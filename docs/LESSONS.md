# 经验教训（LESSONS）

两轮开发（列版 OCR 流水线 → 高亮岛流水线）与 10 页端到端实测的结论，供后续项目直接引用。

## 1. 引擎选型

1. **Windows.Media.Ocr(ja) 已弃用**：对艺术字/连笔误读率太高（`ョドーシ〕が`、`、た、か。らこそ`、
   `繋が切を` 等）。保留代码但不进入默认路径。
2. **manga-ocr = 文本权威**：漫画专用训练，整岛一次识别质量最高（能读出 Paddle 拼不出的整句）。
   无检测/无置信度——几何与核对信号只能靠 Paddle。
3. **PaddleOCR = 几何权威 + 佐证**：整页识别碎片化严重（列序错乱、低置信）；**岛级 crops
   （raw/raw2x/clahe/otsu 四变体择优）**显著改善置信与文本（27/004 `腕弱さだ`0.78→`脆弱さだ`0.98、
   33/004 `閣属性や`→`闇属性を`0.94），但个别岛反而变差（33/009 退化成 `は`）——交叉验证而非单挑。
4. **原图重读优于填黑图**：filled_black 黑背景会让 manga-ocr 误读（`間属性` vs 原图 `闇属性`）。
   REVIEW 岛用**原 bbox + original.jpg** 重读是最高性价比修复（18→8 REVIEW）。
5. **bbox 扩区有害**：外扩改变裁剪缩放比例，manga-ocr 反而变差（`ワテクア→ワケクア`）；
   且被截断的文字在填黑图里已是黑背景、扩区救不回。已取消扩区，黄色描边仅作可视化（6px，可配）。

## 2. 数据与几何

6. **几何权威 = islands.json 的 image_bbox**；image_polygon 是近似轮廓（交接文档明确非权威），
   仅用于展示与擦字 mask——严格 point-in-polygon 会误杀真实文本（island_010 `ワテクア` 中心在
   锯齿轮廓外），改为 bbox 为准 + polygon 违反降级软告警。
7. **微岛标准**：`image_area < 800px²` 舍弃（island_006 132px²、007 451px² 均为噪声），
   不擦/不译/不嵌，审计记录 dropped_tiny。
8. **归属取最小面积包含岛**：bbox 修正/重叠时，微小岛的 `．．．` 行会落入相邻岛扩展 bbox 并
   覆盖其 manga 文本（33/004 被 island_006 的 `.` 行覆盖）——按最小面积容器分配。

## 3. 擦字与像素完整性

9. **擦字 mask 一律裁剪到岛内**：字形检测的膨胀（≤6px）会越出岛边界（首版每页 122~23693 像素
   越界）——裁剪到岛几何后"岛外零改动"是结构保证而非仅审计。
10. **岛并集掩膜裁剪兜底**：描边/抗锯齿字形会溢出分析框 2-3px，最终合成按岛并集掩膜裁剪
    （岛外像素强制=擦字图），边缘描边轻微裁切可接受。

## 4. 翻译

11. **提示词泄漏三层校验**：Sakura 对短/特殊岛会原样吐上下文（`是岛_001: ああ`、`（无） 术语表…`）。
    校验必须覆盖：提示字段（本页前文/术语表/（无）等）、**上下文其他岛文本片段**、kana 比例与长度。
12. **?/! 保留规则在岛场景误杀**：OCR 噪声 `？という訳で…` 的合法译文 `于是……` 被列版校验拒绝
    ——岛版缓存校验去掉标点保留规则。
13. **kept-source 约定**：两轮提示（contextual→concise）都失败 → 判定符号/拟声岛（`ス`、`の．．．`、
    `！！？`），译文=原文（绝不留空岛），决策缓存 `*.kept.json` 免重复请求；M4 仍嵌字回原符号。
14. **缓存签名绑定**：原文 SHA（final.json effective_sha）+ 模型 + 提示版本 + precision + 上下文
    列表；改原文/换引擎即失效，不串页。二次运行 58/58 命中验证。
15. **online 整页打包**：一页所有岛编号一次请求（`编号: 译文` 逐行解析），缺号/失败静默回退 local；
    页级缓存按页签名。

## 16. 排版

16. **纯竖排**：漫画基本无横排文本，删除横排分支；阅读顺序右→左（曾因 `sorted(..., reverse=True)`
    把第一列放到最左——右→左 bug 必须用单测锁住）。
17. **面积比双模式**：中文比日文短，列位跟随（A_text/A_base_union）常 <60%——
    触发**模式 2（外接矩形）**：居中块 + 基准换行集外接矩形 A_rect + 加大字号，33/005 0.42→区间内、
    33/014 0.24→1.06；min_ratio 默认 0.6 可配；仍不达标 → pending_review 不硬失败。
18. **A_base 定义**：行框**并集面积**（掩膜统计），外接矩形仅用于中心；无 Paddle 行岛跳过面积比。
19. **间距参数化**：字距=字号//16、列距=字号//4，块尺寸与绘制同公式（排版准确）。
20. **中心锁定**：偏移 ≤ 岛对角线×5% 圆形；shift 需按岛缘 clamp（首版公式把 shift 钳成 0，
    导致偏移虚高）。
21. **max_size 起点**：`min(宽,高)/2` 对窄长岛（39px）太小——应为 `min(宽,高)`。

## 5. 流程与工程

22. **双引擎交叉验证一致性** = 归一化后 Paddle 片段包含于 manga 文本（顺序以 manga 为准）；
    片段全为短字符时回退编辑距离（否则 `は` 单字假通过）。
23. **懒人开关默认开**：REVIEW 直接承认 manga（文本权威），风险记录保留；关闭才逐项核对。
24. **state 重嵌防串用**：四路 SHA（original/islands/erased/translations）绑定，任一不符拒绝。
25. **环境单化**：两仓合并后单一 venv（PySide6/PIL/numpy/jsonschema/winrt/manga_ocr/opencv-contrib）
    + paddle_venv；opencv 需 contrib 包才有 xphoto（FSR 修复依赖）。
26. **删除式整理**：15.5GB 历史备份 zip、旧 exe、旧比较产物直接删除（git 接管版本）；
    旧 GUI/列版测试归档 legacy/，避免死代码干扰新流程。
